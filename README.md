# Tiro Adventure

Cuide do Tiro, um cachorrinho em pixel art: plante, colha, cozinhe e cumpra missões para
mantê-lo feliz e desbloquear novos lugares. Explore sete passeios com materiais, diário e apetrechos
raros garantidos após algumas voltas. O Tiro chega filhotinho e cresce em cinco fases até o Tiro azul e dourado,
guardando fotos num álbum e deixando marcas na Casa. Jogável no navegador e instalável no celular como app (PWA).

**Jogar:** https://vitorawi.github.io/tiro-adventure/

## Instalar no celular
- **iPhone (Safari):** abra o link → botão Compartilhar → "Adicionar à Tela de Início".
- **Android (Chrome):** abra o link → menu ⋮ → "Instalar app" / "Adicionar à tela inicial".

O progresso fica salvo no próprio aparelho.
